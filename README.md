- `linear_only_u_curve.png`: **robust U-shaped** curve in the **Bank Marketing** dataset
- `noise_sweep_estimation_cv.png`: test error vs the noise **dimension** within the previliged information W
- `signal_sweep_estimation_cv.png`: test error vs the **signal strength** in the previliged information W
- `unlabeled_sweep_estimation_cv.png`: test error vs the **unlabeled sample size** (m)
